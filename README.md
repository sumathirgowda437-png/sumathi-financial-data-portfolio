# Sumathi R - Finance Operations & Financial Data Analyst Portfolio

This is a lightweight, responsive portfolio site focused on finance operations, accounts receivable, investment data, financial reporting, SQL, and Power BI. It is built with plain HTML, CSS, and JavaScript and is designed to be easy to host on GitHub Pages, Netlify, or another static host.

## GitLab Pages

The included `.gitlab-ci.yml` publishes the contents of `dist/` whenever a change is pushed to the default branch. After the GitLab pipeline finishes, open **Deploy > Pages** in the project to find the public portfolio URL.

## GitHub Pages

The included GitHub Actions workflow publishes `dist/` to GitHub Pages after every push to the `main` branch. In the GitHub repository, select **Settings > Pages > GitHub Actions** to enable it.

## Local preview

Open `dist/index.html` in a browser, or serve the `dist` folder with any static web server.

## Update contact and projects

- Edit `dist/index.html` for text and project details.
- Edit `dist/styles.css` for visual styling.
- Replace `dist/assets/Sumathi_R_ATS_Resume.pdf` when the resume changes.
